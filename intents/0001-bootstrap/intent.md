# 0001 bootstrap

등급: M — 되돌리기 비싼 변경 없음. 레포 골격과 개발 도구만 만든다.

## 문제

에이전트에게 구현을 맡길 기반이 없다.
검사 명령, 훅, 리뷰 형식, CI가 없으면 에이전트가 스스로 검증할 수 없다.

## 기대 결과

- `npm run check` 하나로 타입체크, 린트, 포맷, 테스트가 돈다.
- 훅이 위험한 동작(배포, 시크릿 편집)을 막는다.
- PR을 열면 CI가 검사와 등급 라벨을 확인한다.
- 다음 intent(0002-capture)를 이 흐름으로 바로 시작할 수 있다.

## 영향 범위

레포 루트 설정 파일, `.claude/`, `.github/`, `docs/`, 최소한의 `src/worker.ts`.
