# ADR 0001: 메신저는 텔레그램, 봇 프레임워크는 grammY

- 상태: 채택 (2026-10-17)

## 맥락

- 모바일 공유 시트로 링크를 보내고, 봇이 먼저 다이제스트를 보내야 한다.
- 메시지 안 버튼으로 바로 처리해야 한다.
- 개인이 무료로, 승인 절차 없이 만들 수 있어야 한다.

## 결정

- 메신저는 텔레그램을 쓴다.
- 봇 프레임워크는 grammY를 쓴다.

## 이유

- 텔레그램만 세 조건(공유 시트, 봇이 먼저 발송, 인라인 버튼)을 무료로 만족한다.
- 카카오톡 채널 챗봇은 봇이 먼저 메시지를 보내려면 유료·사업자용 기능이 필요하다.
- grammY는 TS 텔레그램 봇 라이브러리 중 가장 많이 쓰인다 (npm 주간 다운로드: grammY 약 460만, Telegraf 약 26만, 2026-10 기준).
- grammY는 Workers에서 돌고, Bot API 타입을 최신으로 유지한다.

## 대안

- Discord, Slack: Slack 무료 플랜은 메시지 기록이 90일로 제한된다.
- Bot API를 fetch로 직접 호출: 의존성은 줄지만 타입과 업데이트 파싱을 직접 관리해야 한다.

## 결과

- grammY 의존 코드는 `src/adapters/telegram/`에만 둔다. `src/core/`는 grammY를 모른다.
